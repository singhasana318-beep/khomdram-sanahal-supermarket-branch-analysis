# Supermarket Branch Performance Analysis

## Overview

This dashboard compares branches and cities, tracks branch sales over time, and identifies practices worth replicating.

## Dataset

The supplied project dataset is included in `data/supermarket_sales_500_rows.csv`. It contains 500 supermarket transactions and 13 fields. Once this repository is uploaded, the GitHub URL for that file is the accessible dataset link for evaluators.

## Technologies

- Python
- Streamlit
- pandas
- Plotly

## Install and run

```bash
python -m pip install -r requirements.txt
streamlit run Khomdram_Sanahal_SupermarketBranchAnalysis.py
```

## Repository contents

- `Khomdram_Sanahal_SupermarketBranchAnalysis.py` - runnable dashboard
- `requirements.txt` - dependencies
- `Khomdram_Sanahal_Project_Report.docx` - project documentation
- `README.md` - setup instructions
- `data/supermarket_sales_500_rows.csv` - supplied project dataset
